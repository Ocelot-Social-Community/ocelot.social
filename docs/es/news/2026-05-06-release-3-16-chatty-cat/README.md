## Destacado: Salas de chat en grupos

Con *ocelot.social* Chatty Cat (3.16), cada grupo dispone de su propia sala de chat donde los miembros del grupo pueden comunicarse entre sí.
Ahora pueden comunicarse de forma independiente a las publicaciones y todos pueden ver lo que se ha escrito.

Esto fue posible gracias a las donaciones de nuestra [segunda campaña de crowdfunding](/es/news/2026-03-03-crowdfunding-feature-chat-for-groups/).
¡Un enorme agradecimiento a todos los que apoyaron esto – sin vosotros, esta actualización no existiría!

## Nuevas funciones

- Salas de chat en grupos
- Número de nuevos mensajes visible directamente en los perfiles
- Silenciar un grupo evita las notificaciones por correo de nuevos mensajes de chat
- Mejoras del editor
- Marcar notificaciones como leídas/no leídas
- Mapa mejorado:
  - mejor rendimiento y estabilidad
- Ícono más intuitivo para el selector de idioma
- Página de invitaciones en los ajustes:
  - con lista de enlaces de invitación
  - con lista de usuarios que se unieron gracias a tus invitaciones
- Claves API: crear y gestionar en los ajustes
  - Gestión para administradores del sistema
- Diseño de correo configurable para desarrolladores
- Diversas optimizaciones
- Pruebas de software para el control de calidad

## Errores corregidos

- Fallos en el chat
- Recuento de publicaciones incorrecto en algunos perfiles
- Fallos en redes sociales
- Mapa: fallo con publicaciones fijadas sin ubicación

## Bajo el capó
