## Highlight: Group Chat Rooms

With *ocelot.social* 3.16 Chatty Cat, every group gets its own chat room where group members can communicate with each other.
They can now communicate independently of posts, and everyone can see what has been written.

This was made possible thanks to donations from our [second crowdfunding campaign](/en/news/2026-03-03-crowdfunding-feature-chat-for-groups/).
A huge thank you to everyone who supported this – without you, this update would not exist!

## New Features

- Group chat rooms
- Number of new messages visible directly on profile pages
- Muting a group prevents email notifications about new chat messages
- Editor improvements
- Mark notifications as read/unread
- Map improved:
  - better performance and stability
- More intuitive icon for the language switcher
- Invitation page in settings:
  - with list of invitation links
  - with list of users who joined through your invitations
- API Keys: create and manage in settings
  - Management for system administrators
- Email design configurable for developers
- Various optimizations
- Software tests for quality assurance

## Bug Fixes

- Chat malfunctions
- Occasionally incorrect post count on profile pages
- Social media malfunctions

## Under the Hood

- Countless updates under the hood
- Security and stability
