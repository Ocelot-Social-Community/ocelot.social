## Highlight: Gruppen-Chaträume

Mit *ocelot.social* 3.16 Chatty Cat erhält jede Gruppe einen eigenen Chatraum, indem sich die Mitglieder der Gruppe austauschen können.
Diese können nun unabhängig von Beiträgen miteinander kommunizieren und alle sehen, was geschrieben wurde.

Dies wurde dank der Spenden im Rahmen unseres [zweiten Crowdfundings](/de/news/2026-03-03-crowdfunding-feature-chat-for-groups/) ermöglicht.
Wir danken allen Spendern herzlich dafür, dass ihr dies ermöglicht habt!
Ein riesiges Dankeschön an alle, die dieses unterstützt haben – ohne euch gäbe es dieses Update nicht!

## Neue Funktionen

- Gruppen-Chaträume
- Anzahl neuer Nachrichten direkt auf Profilseiten sichtbar
- Stummschalten einer Gruppe verhindert E-Mail-Benachrichtigungen über neue Chat-Nachrichten
- Verbesserungen des Editors
- Benachrichtigungen als gelesen/ungelesen markieren
- Karte verbessert:
  - mehr Performance und Stabilität
- intuitiveres Logo für den Sprachumschalter
- Einladungsseite in den Einstellungen:
  - mit Liste der Einladungslinks
  - mit Liste der aufgrund deiner Einladungen beigetretenen Nutzer
- API-Keys: Anlegen, Verwalten in den Einstellungen
  - Verwaltung für Systemadministratoren
- E-Mail-Design konfigurierbar für Entwickler
- verschiedene Optimierungen
- Software-Tests zur Qualitätssicherung

## Behobene Fehler

- Fehlfunktionen des Chats
- teilweise fehlerhafte Beitragsanzahl auf Profilseiten
- Fehlfunktionen bei Sozialen Medien
- Karte: Crash bei angehefteten Beiträgen ohne Standort
